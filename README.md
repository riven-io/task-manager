
# Task Manager

A minimalist task manager built with HTML, CSS and vanilla JavaScript.

Designed to provide a clean, distraction-free space to organize daily tasks.

## Features

- **Add tasks** — quickly create new tasks.
- **Edit tasks** — update task descriptions with Save and Cancel options.
- **Keyboard shortcuts** — press Enter to save changes or Escape to cancel editing.
- **Complete tasks** — mark tasks as completed or reopen them.
- **Delete tasks** — remove tasks you no longer need.
- **Persistent storage** — tasks are saved in the browser using localStorage.
- **Remaining task counter** — keep track of unfinished tasks.
- **Empty state** — a clean interface when there are no tasks.

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Browser localStorage

## Getting Started

No installation or dependencies required.

1. Clone the repository:

   ```bash
   git clone https://github.com/riven-io/task-manager.git
   ```

2. Open the project folder:

   ```bash
   cd task-manager
   ```

3. Open `index.html` in your browser.

## Data Storage

Tasks are stored locally in the browser using `localStorage`. Your tasks persist between visits in the same browser, but are not synchronized across devices.
